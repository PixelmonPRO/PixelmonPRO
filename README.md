## 🚀 Featured Projects

### Pixelmon.PRO

<img src="https://github.com/PixelmonPRO/PixelmonPRO/blob/main/assets/pixelmonpro-logo.png" alt="Pixelmon.PRO" width="500"/>

Pixelmon.PRO is a full-stack Minecraft server infrastructure project. It includes everything from custom launcher development to Forge/Sponge/NeoForge mod integration. We've also built a comprehensive Russian localization system, Docker-based server management, and a modpack distribution platform.

**Tech Stack:** Java 8/21/25 • JavaScript • Groovy • MySQL/MariaDB/PostgreSQL/SQLite • Redis • Docker • Prometheus/Grafana/Loki • Gradle • Kotlin • Bash

**Links:** [Website](https://pixelmon.pro) • [GitHub Organization](https://github.com/TeamPixelmonPRO)

### SoundCloud | Drum and Bass Bot

<img src="https://github.com/PixelmonPRO/PixelmonPRO/blob/main/assets/soundcloudbot-logo.png" alt="SoundCloud | Drum and Bass Bot" width="500"/>

This is an event-driven Telegram bot that keeps an eye on SoundCloud for new Drum & Bass releases. It automatically downloads the tracks and sends them to subscribers. It's built with a Spring Boot microservice architecture, async threading, a PostgreSQL database, and a media processing pipeline.

**Tech Stack:** Java 25 • Spring Boot 3.5.6 • PostgreSQL • Flyway • Python • yt-dlp • ffmpeg • Telegram Bot API • Docker • Prometheus/Grafana/Loki • Gradle • Redis

**Status:** Closed Source

### Java Version Manager

<img src="https://github.com/PixelmonPRO/PixelmonPRO/blob/main/assets/javamanager-logo.png" alt="Java Version Manager" width="500"/>

A handy PowerShell script for Windows that makes it easy to find, install, switch between, and manage multiple JDK/JRE versions from different providers.

**Tech Stack:** PowerShell • Bash • Git • GitHub Actions • CI/CD

**Links:** [GitHub](https://github.com/PixelmonPRO/Java-Version-Manager)
